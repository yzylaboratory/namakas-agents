# Mapa base de obligaciones (referencia)

Referencia de trabajo para `mapear-obligaciones-regulatorias`. No es un inventario exhaustivo ni dictamen. Actualizar con fuente + fecha al usarlo en un memo o gate.

Última revisión de esta nota: **2026-08-04**.

## Cómo usar

1. Copia filas relevantes al registro de la misión.
2. Verifica vigencia en la fuente propietaria.
3. Marca estado: confirmada / provisional / en transición / no aplica.

## Privacidad / datos personales

| Tema | Instrumento / guía | Notas |
|---|---|---|
| Principios y bases legales | GDPR (UE) 2016/679 | Controlador/encargado; accountability |
| Data protection by design/default | GDPR Art. 25; EDPB Guidelines 4/2019 v2.0 | Minimización, default restrictivo |
| Transferencias / encargados | GDPR Caps. IV–V | DPAs, garantías |
| Jurisdicciones LATAM | LGPD (BR) y normas locales | No asumir equivalencia automática con GDPR |

## Open Banking / Open Finance

| Jurisdicción / esquema | Instrumento | Notas |
|---|---|---|
| Brasil | Resolução Conjunta nº 1 BCB + actos en openfinancebrasil.org.br | Consentimiento, participantes, gobernanza |
| UE (pago/cuenta) | PSD2 / NextGenPSD2 (Berlin Group) | SCA, AIS/PIS; openFinance = extensiones premium no = ley única |
| UE openFinance industria | Berlin Group openFinance Framework | Estándar de industria; separar de mandato PSD2 |
| Australia | CDR / Consumer Data Standards | Acreditación, estándares de datos |
| EE.UU. | CFPB Personal Financial Data Rights / §1033 | Verificar estado litigioso/transición antes de afirmar vigencia |

## Contratos / alianzas (capa típica)

| Tema | Qué vigilar |
|---|---|
| API terms / partnership | Licencia de datos, uso permitido, audit rights |
| DPA / encargados | Instrucciones, subencargados, brechas, retorno/borrado |
| Deprecación | Aviso, ventana, responsabilidad por breaking changes |
| Responsabilidad / indemnidad | Caps alineados a riesgo regulatorio y de datos |
