# Criterios para descubrir y seleccionar skills

Una capacidad merece una skill cuando:

- Se usa repetidamente.
- Tiene un procedimiento no obvio.
- Depende de estándares, herramientas o convenciones específicas.
- Tiene errores frecuentes o casos límite relevantes.
- Produce un entregable verificable.

No merece una skill cuando:

- Solo repite la descripción del rol.
- Es conocimiento básico que el modelo ya aplica bien.
- Es una instrucción permanente; debe ir en Reglas.md.
- Es una tarea única sin posibilidad real de reutilización.
- Mezcla varias responsabilidades no relacionadas.

## Tamaño

Prefiere entre cuatro y ocho skills por agente especializado. Un director puede requerir skills adicionales de coordinación. La cantidad final depende del dominio, no de una cuota ceremonial.
