# Checklist de calidad del agente

## Identidad

- [ ] Personaje único.
- [ ] Personalidad alineada con el rol.
- [ ] Riesgos de personalidad controlados.

## Rol

- [ ] Misión exclusiva.
- [ ] Entradas y salidas claras.
- [ ] Autoridad y límites definidos.
- [ ] Indicadores observables.

## Reglas

- [ ] Permanentes y no procedurales.
- [ ] Sin contradicciones.
- [ ] Seguridad y cumplimiento incluidos cuando aplican.

## Delegación

- [ ] Responsables correctos.
- [ ] Contrato autocontenido.
- [ ] Criterios de escalamiento.

## Skills

- [ ] Nombres válidos.
- [ ] Descripciones activables.
- [ ] Alcance coherente.
- [ ] Procedimiento accionable.
- [ ] Salida y validación.
- [ ] Fuentes actuales.
- [ ] Casos de evaluación para skills críticas.

## Adaptadores

- [ ] Cursor creado.
- [ ] Claude creado.
- [ ] Permisos mínimos.
- [ ] Rutas relativas.

## Cierre

- [ ] Validador sin errores.
- [ ] Catálogo actualizado.
- [ ] Cambios resumidos.
