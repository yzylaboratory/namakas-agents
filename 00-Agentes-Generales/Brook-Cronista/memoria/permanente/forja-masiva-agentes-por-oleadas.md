# Forja masiva de agentes por oleadas individuales

Convención operativa Nakamas (capturada 2026-08-04):

1. **Forja de contenido canónico** (Personalidad, Rol, Reglas, Delegación, adapter `.cursor/agents`) se hace con Tasks **individuales** de `vegapunk-forjador-agentes`, no con un batch monolítico si el batch se aborta o no es fiable.
2. **Organigrama + live roster** son un paso **aparte**: se puede dejar `organigrama.yaml` en stub a propósito mientras se completa la oleada de archivos canónicos.
3. **“Forjado” ≠ “vivo”**: tener Personalidad y adapter no implica asiento en reglas live / Activity registry hasta consolidación explícita.
4. Tras una oleada, Brook deja bitácora + decisión; Vegapunk (o Luffy) cierra la alineación roster/organigrama.
