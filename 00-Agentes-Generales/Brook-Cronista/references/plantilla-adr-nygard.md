# Plantilla ADR (Michael Nygard)

Fuente primaria: Michael Nygard, Cognitect — *Documenting Architecture Decisions* (2011-11-15):
https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions

Usar para decisiones que afecten estructura, características no funcionales, dependencias, interfaces o técnicas de construcción.

```md
# ADR NNNN: Título corto en frase nominal

## Status

proposed | accepted | deprecated | superseded by [ADR MMMM](./MMMM-titulo.md)

Fecha: YYYY-MM-DD
Decisores: [agentes / personas]
Misión relacionada: [id o enlace a diario]

## Context

Fuerzas en juego (técnicas, de proyecto, organizativas). Lenguaje neutro: hechos y tensiones, no justificación retórica.

## Decision

Respuesta en voz activa: "Haremos…" / "Usaremos…".

## Consequences

Efectos positivos, negativos y neutrales. Qué se vuelve más fácil o más difícil.
```

## Naming de archivo

`memoria/adr/NNNN-titulo-kebab.md` — ejemplo: `0001-solo-luffy-y-vegapunk-vivos.md`
