# Framework de métodos UX (referencia Chopper)

Síntesis operativa para selección de método. No sustituye las fuentes primarias.

## Dimensiones (NN/g)

1. **Actitudinal vs comportamental** — lo que dicen vs lo que hacen.
2. **Cualitativo vs cuantitativo** — por qué / cómo arreglar vs cuántos / cuánto.
3. **Contexto de uso** — natural, scripted, producto limitado, sin producto.

## Fase en el tiempo

| Fase | Objetivo | Ejemplos |
|---|---|---|
| Strategize (generativo) | Dirección y oportunidades | Field, diary, interviews, concept testing |
| Design (formativo) | Mejorar el diseño | Usability testing, card sorting, tree testing, prototype feedback |
| Launch & Assess (sumativo) | Medir / comparar | Benchmarking, surveys a escala, A/B, analytics |

## Regla práctica de N

- Usability cualitativo: ~5 usuarios por grupo homogéneo; preferir varios estudios pequeños a uno enorme.
- Varios grupos distintos: ~3–4 por grupo.
- Cuantitativo: N mucho mayor; no reportar “% de usuarios” con N cualitativo pequeño.

## Ética mínima

Consentimiento informado: propósito, formato, datos, retención, retiro, observadores/grabación. Anonimizar en entregables.
