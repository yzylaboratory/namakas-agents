# Preparar revisión de negocio de cuenta

## Propósito

Convertir la cadencia QBR/RBR en un foro de outcomes: progreso del plan, valor entregado, riesgos y decisiones — no un monólogo de roadmap.

## Entradas

- Plan de cuenta actual (o declaración de ausencia).
- Métricas disponibles (uso, SLAs, NPS/CSAT, pipeline, NRR si existe).
- Audiencia (cliente ejecutivo, interno, mixto) y duración.
- Decisiones pendientes (renewal, expansión, remediación).

## Procedimiento

1. Define objetivo de la revisión (alinear, decidir renewal, desbloquear expansión, remediación).
2. Arma agenda timeboxeada: outcomes → scorecard → riesgos → decisiones → next steps.
3. Construye scorecard mutuo (compromisos nuestros vs métricas del cliente).
4. Selecciona wins con evidencia; no inventes ROI.
5. Prioriza 3–5 riesgos/issues con owner propuesto.
6. Prepara decisiones requeridas (sí/no/fecha) y materiales de soporte.
7. Lista follow-ups pre-asignados (owner + due) para cerrar en la sala.
8. Si faltan datos, declara gaps y reduce claims.

## Salida

```md
## Objetivo / audiencia / fecha
## Agenda
## Scorecard
## Wins (con evidencia)
## Riesgos / issues
## Decisiones requeridas
## Follow-ups (owner + due)
## Anexos / datos faltantes
```

## Casos límite

- Sin plan de cuenta → QBR de remediación (crear plan) + no fingir madurez SAM.
- Cliente solo quiere “features nuevas” → reencuadra a value map; escala producto si aplica.
- Métricas ausentes → scorecard cualitativo etiquetado + plan de instrumentación.

## Validación

- Agenda con outcomes y decisiones.
- Follow-ups con owner + due.
- Claims cuantitativos con fuente o marcados como inferencia.
- No incluye pricing final ni cláusulas legales inventadas.

## Criterios de terminado

- El facilitador puede correr la reunión con el paquete.
- Post-QBR tiene lista de follow-ups lista para tracking.

## Casos de evaluación

| Caso | Entrada | Resultado esperado |
|---|---|---|
| Normal | Plan fresco + métricas de uso | Paquete QBR completo |
| Ambiguo | “Prepara el QBR” sin métricas | Agenda + gaps + scorecard mínimo |
| Límite | Relación en riesgo / champion quiet | QBR de remediación + riesgos top + multi-thread |
