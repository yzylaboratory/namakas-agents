# Analizar competencia y mapa de posicionamiento

## Propósito

Entender el set competitivo (directo, indirecto, status quo) y ubicar la oferta en ejes que el buyer percibe, identificando puntos de diferencia (POD), puntos de paridad (POP) y whitespace.

## Entradas

- Target segment(s) priorizados.
- Lista conocida de competidores / sustitutos.
- Evidencia pública (sites, pricing, reviews, win/loss).
- Categoría o frame of reference propuesto.

## Procedimiento

1. Define el set competitivo por target (incluye “do nothing” / Excel / proceso manual si aplica).
2. Inventaría atributos visibles: precio, velocidad, compliance, DX, cobertura, soporte, trust.
3. Elige 2 ejes perceptibles para el mapa (evita ejes internos opacos como “arquitectura microservicios”).
4. Ubica competidores y la oferta propia con evidencia por celda (cita).
5. Declara POD deseados vs POP obligatorios de la categoría.
6. Señala overcrowded zones y whitespace creíble (no fantasía).
7. Lista riesgos: table stakes no cubiertos, claims no defendibles, guerra de precio.

## Salida

```md
## Target de referencia
## Set competitivo
## Evidencia por rival (fuentes)
## Ejes del mapa y justificación
## Mapa / posiciones
## POD / POP
## Whitespace y no-go
## Implicaciones de posicionamiento
## Riesgos
```

## Casos límite

- Competidor dominante en ambos ejes → plantea reframe de categoría o niche.
- Solo hay 1 rival conocido → amplía a sustitutos y status quo.
- Evidencia solo anecdótica → marca confianza baja; no inventes features del rival.

## Validación

- Ejes son comprensibles para el buyer del target.
- Cada posición material tiene fuente o supuesto.
- POP críticos no se omiten al “diferenciarse”.

## Criterios de terminado

- Se puede redactar un positioning statement sin contradecir el mapa.
- Gaps de evidencia están listados.

## Casos de evaluación

| Caso | Entrada | Resultado esperado |
|---|---|---|
| Normal | 4 vendors + target bank IT | Mapa 2×2 + POD/POP |
| Ambiguo | “Analiza la competencia” | Pregunta de target + set preliminar |
| Límite | Sin sites públicos | Win/loss interno + limitaciones explícitas |
